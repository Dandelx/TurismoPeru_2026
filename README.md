# 🏦 Proyecto Base de Datos - TURISMOPERU_EACM

## 📘 Descripción General
Sistema web desarrollado en Flask para registrar, consultar y administrar información de personas y clientes en el sector turístico.

## 🚀 Fases del Proyecto
1. Configuración de Base de Datos y Stored Procedures en SQL Server.
2. Desarrollo del backend con Python, modelos y controladores.
3. Creación de vistas web dinámicas e integración con Git/GitHub.

## 🧠 Competencias a Desarrollar
* Manejo de bases de datos relacionales y ejecución de procedimientos almacenados.
* Desarrollo de aplicaciones web backend con Python, Flask y control de versiones.
